# Gestor de Tareas

Aplicación de consola desarrollada en Python para gestionar tareas desde un menú interactivo.

## Funcionalidades

- Agregar tareas.
- Ver tareas pendientes y completadas.
- Marcar tareas como completadas.
- Eliminar tareas.
- Validar entradas del usuario.
- Guardar tareas automáticamente en un archivo JSON.
- Cargar las tareas al iniciar el programa.
- Manejar archivos inexistentes o JSON inválido.

## Tecnologías

- Python 3.10+
- JSON
- Biblioteca estándar de Python

## Ejecución

Clona el repositorio y ejecuta:

```bash
python main.py
